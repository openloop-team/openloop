# NNNN — Decision as a verb phrase

- **Status:** Proposed
- **Date:** YYYY-MM-DD
- **Implementation:** what this authorizes touching; what it leaves otherwise
  unchanged. Omit this bullet when Decision already says where the record
  stops.

## Context

What is true now, and what about it forces a choice. Written so that a reader
with no other source can follow it — no links to untracked documents, and no
vocabulary borrowed from one.

The alternatives, each stated at its strongest, and why each was rejected. If
they collapse on inspection there was no decision here to record.

## Decision

The decision, in one sentence.

- One constraint per bullet, as a modal (must, never, only, owns, requires) or
  as a plain invariant. Each should survive a change in how it is implemented:
  if it would need editing once the implementation changed shape, it is spec
  and belongs in the design document instead.

## Consequences

- What gets harder, what is given up, what must now be done differently.
- What a later record would have to supersede in order to reverse this one.
